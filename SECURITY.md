# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/thenolle/scantling/security/advisories/new). Do not open a public issue.

Include the affected version, steps to reproduce, and the impact you observed. You can expect an acknowledgement within a few days. Fixes are published in a release with credit to the reporter unless you prefer otherwise.

## Scope

Scantling runs locally and handles source code, conversations and files. Reports about path traversal, command execution limits, permission bypass, secret leakage into training data, and prompt injection that escalates privileges are all in scope.
