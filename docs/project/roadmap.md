# Roadmap

The project is built in small, tested increments.

| Stage                | Scope                                                | Status      |
| -------------------- | ---------------------------------------------------- | ----------- |
| Foundation           | Workspace, audit, CI, releases, documentation site   | In progress |
| Tensors and autodiff | Tensor core, matmul, gradients with numerical checks | Planned     |
| Tokenizer and model  | BPE tokenizer, Transformer, inference                | Planned     |
| Training             | Datasets, optimizers, checkpoints, evaluation gates  | Planned     |
| Mathematics and code | Exact and symbolic math, repository analysis, agent  | Planned     |
| Search and memory    | Search providers, fact-checking, local memory        | Planned     |
| Application          | Gambrel interface connected to the services above    | Planned     |

Progress is recorded in the [changelog](https://github.com/thenolle/scantling/blob/master/CHANGELOG.md).
